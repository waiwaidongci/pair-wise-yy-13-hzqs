# DiffScope 代码审查工作台

基于 React、TypeScript、Vite、Monaco Editor、MUI、Zustand、TanStack Query 和 React Router 的大差异审查工具。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
corepack pnpm test:sync   # 合并引擎冒烟测试（无需浏览器）
```

## 功能

- Monaco 提供的并排与行内 Diff 模式、语法高亮、单词级差异和虚拟滚动。
- 折叠未修改区域，F7 / Alt+↓ 快速跳转下一处修改。
- 文件树显示新增/删除行数与签收状态。
- 任意行添加评论、回复评论、标记解决，并在编辑器中显示评论定位标记。
- mock patch 在本地生成，不依赖后端服务。

## 多标签页协同审阅

两个标签页看同一变更集时，审阅进度不再互相整份覆盖。共享事实源是
localStorage 中的 `diff-scope-shared-v2`（`SharedReviewDoc`），每个标签页本地只持有
镜像 + 待提交操作（sessionStorage，刷新不丢）：

- **审阅批次**：每次提交落库为一个批次（`ReviewBatch`），评论线程与文件签收都挂在
  批次上；批次号同时是重试的幂等键（`appliedBatchIds`）。
- **文件认领租约**：提交按文件串行——同一文件先到者领走（默认 45s），超时或对方
  「交回」后别人才能接手；被挡住的操作保留在现场并自动重试。也可以手动
  「认领 / 交回 / 接手」。
- **三方合并**：提交时以待提交操作捕获的基线值与共享文档对比——只有一边动过的
  直接采用；两边都改过同一实体（签收、评论删除/解决状态）就各留一份生成冲突单，
  对应文件被挡住不能完成签收，在「冲突」面板裁决后才能提交。
- **变更集版本**：每个文件有内容哈希；变更集一改动，改动文件的签收失效、评论按
  锚点（行文本 + 上下文）重算定位，找不到的标记「定位失效」，其他文件照旧。
- **合并失败保留现场**：远端文档损坏等异常会保留待提交操作、批次号与远端原文，
  「重试」用同一批次号恢复，不会重复追加线程。
- **迁移**：旧版本地数据（`diff-scope-review-v1`，缺批次与持有人）首次启动时迁移成
  首版共享文档（schemaVersion 1），原数据备份为 `*.migrated`。

顶栏提供「模拟变更集更新」「模拟合并失败」两个演示按钮，配合两个浏览器标签页
即可复现认领、冲突、裁决与重试的完整链路。

## 目录

- `src/sync/` — 哈希与变更集、锚点重算、操作与视图推导、三方合并、共享文档读写与迁移、标签页身份
- `src/stores/reviewStore.ts` — 本地状态 + 提交/拉取编排
- `scripts/smoke.ts` — 合并引擎冒烟测试（`corepack pnpm test:sync`）
